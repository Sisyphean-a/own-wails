# SmartAnnounce TTS 播报

`scope: context:smart-announce`

## 范围

本上下文只适用于 `SmartAnnounce/` 将中文促销文案生成 MP3 播报并在桌面端试听、循环播放和导出的流程。

## 通用语言

- **播报文案**：用户输入并提交给 TTS 的文本；首尾空白会被规范化。
- **音色**：Minimax 的 `voice_id`，必须由用户选择。
- **生成音频**：TTS 返回并写入本地文件的 MP3 数据。
- **试听数据**：供当前页面 HTML Audio 播放的 Base64 Data URI，不是持久化真源。
- **导出**：通过 Wails 原生保存对话框，把已生成的本地 MP3 复制到用户指定路径。

## 稳定规则

1. `MINIMAX_API_KEY` 是生成语音的必要凭证；`MINIMAX_TTS_MODEL` 可选，缺省使用 `speech-2.8-hd`。
2. API Key 不写入设置文件、前端状态或日志；缺少凭证和所有外部请求/响应错误必须显式返回。
3. 文案不能为空且最多 2000 个 Unicode 字符；语速必须在 `0.5..2.0`，生成音量必须在 `0..1`。
4. 生成结果以 MP3 保存到 `Downloads/SmartAnnounce`，试听通过 Data URI 使用，导出使用保存对话框选择的目标。
5. 未生成音频时播放和导出必须失败并提示；取消保存对话框不是错误。
6. 已存在的导出目标必须显式失败，不能静默覆盖。
7. TTS 响应必须经过 HTTP 状态、业务状态、音频数据存在性和十六进制解码校验。
