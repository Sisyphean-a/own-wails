# logcat Android 日志查看

`scope: context:logcat`

## 范围

本上下文只适用于 `logcat/` 使用本机 ADB 查看 Android 日志的桌面流程，不扩展为 Android Platform Tools 分发器或通用日志平台。

## 通用语言

- **设备**：ADB 返回的 Android 设备；只有状态为 `device` 的设备可用于日志会话。
- **包范围**：包目录加载范围，取值为 `all`、`user` 或 `system`。
- **绑定**：当前会话的设备、可选包、可选进程和 PID 集；空 PID 集表示不按 PID 收窄。
- **原始日志**：后端有界缓存中的解析日志。
- **可见日志**：过滤器和结果搜索后的集合，前端状态只携带其最后 1000 条。
- **暂停缓冲**：暂停期间仍接收但暂不显示的日志；恢复时可保留或丢弃。
- **过滤器**：针对日志字段的持久化查询；结果搜索是当前可见日志上的独立搜索。
- **SourceIndex**：跨全量状态、追加补丁和选择补丁定位日志的稳定身份。

## 稳定规则

1. 应用从 `adb -s <device> logcat -v threadtime` 读取日志；不内置 Android Platform Tools，也不静默兼容其他日志格式。
2. 一次只能运行一个日志会话；设备、包、进程或 PID 变化时必须取消旧会话。
3. 包相关进程仅指进程名等于包名，或以 `包名:` 开头的进程。
4. 清空只影响本地视图和选择，不执行 `adb logcat -c`。
5. 后端最多保留 100000 条日志；前端增量传输窗口最多 1000 条。
6. 日志、ADB、过滤和导出错误必须显式呈现或返回。
7. 过滤器、默认过滤器和查询历史写入 `logcat-viewer/saved-filters.json`；导出只处理当前可见日志，无可见日志时失败。
8. 状态追加补丁只有在完整基线、上下文和重叠窗口均可验证时才能合并；否则发送或请求完整状态。
