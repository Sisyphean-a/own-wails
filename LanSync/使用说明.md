# 局域同步使用指南

局域同步用于让两台电脑上选定的文件夹自动保持一致。完成首次设置后，日常修改文件通常不需要额外操作。

## 一、使用前准备

- 两台 Windows 电脑连接同一个 Wi-Fi 或路由器，也可以使用网线连接。
- 两台电脑分别打开 `LanSync.exe`。
- 先用不重要的文件测试，确认正常后再添加正式资料。

## 二、首次设置

### 1. 连接另一台电脑

打开「设备」，找到另一台电脑并点击「连接」。确认两边显示的配对码相同，然后分别点击「配对码一致」。

找不到设备时，可按文末的“连接不上怎么办”处理。

### 2. 选择要同步的文件夹

在一台电脑上点击「添加目录」，填写名称、选择本机文件夹，然后发送邀请。

另一台电脑收到邀请后，点击「选择本机目录」，选好对应文件夹，再点击「关联目录」。

两台电脑的文件夹名称和位置可以不同。**以后任一端新增或修改文件，都会同步到另一端。**

### 3. 开始同步

点击「预览并开始」，核对显示的变化，再点击「开始同步」。

需要同步更多文件夹时，重复添加即可；每对文件夹可以单独暂停。

## 三、日常使用

- 正常编辑文件即可，软件会自动同步；也可以点击「立即同步全部」。
- 断网时可以继续编辑。两台电脑重新连接到同一网络、且软件都在运行后，会重新核对并同步。
- **关闭窗口仍会后台运行；点击「退出应用」才会停止。** 如需开机自动运行，可在「设置」中开启「开机启动」。

## 四、文件保护与恢复

| 情况 | 软件如何处理 |
| --- | --- |
| 两边文件内容相同 | 不重复传输 |
| 文件将被替换 | 先备份旧内容；备份失败时不覆盖 |
| 两边都修改，且无法自动合并 | 保留两份，不要求马上选择 |
| 一台电脑删除文件 | 不立即删除另一台的同名文件，等待确认 |

**找回旧内容：** 打开对应目录的「历史版本」。选择「恢复到文件夹」可另存一份；选择「恢复并同步」会先备份当前文件，再恢复旧内容并按正常规则同步。

**处理两份不同内容：** 以 `.md` 结尾的文件支持「查看差异」，可以选择或编辑内容后保存合并；其他文件不提供内容差异查看，但仍会保留两份。

**确认删除前请核对文件名：** 确认后会删除两台电脑上的对应文件。

备份位置可以在「设置」中更改，请选择不参与同步的文件夹。备份不会自动清理，需要留意磁盘空间。

## 五、连接不上怎么办

1. 确认两台电脑都已连接网络，且软件都在运行。
2. 在两台软件的「设置」中点击「允许局域网连接」，按系统提示确认。
3. 仍找不到设备时，在一台的「连接信息」中查看本机地址，将完整地址填到另一台「设备」页面的「输入地址」，再点击「连接」。
